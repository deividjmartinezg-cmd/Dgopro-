# DGOPRO 3.0

Independent probabilistic football forecasting engine.

## Core principle
DGOPRO does not optimize for artificially high displayed probabilities. It optimizes out-of-sample probabilistic accuracy, calibration, discrimination, robustness and explicit uncertainty.

## Challenger-first policy
New components are developed as challengers and must pass temporal/OOS validation, ablation, calibration and independent ARB review before promotion.

## Planned pipeline
T-1 Integrity -> Global Strength 2.0 -> Multi-Horizon Form -> Opponent Adjustment -> Specialist Market Engines -> Ensemble -> Calibration -> Uncertainty -> Selective Prediction -> Drift Monitoring -> ARB Promotion.
